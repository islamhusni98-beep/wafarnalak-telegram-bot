# وفرنالك عروض — Telegram Bot

بوت بسيط لنشر عروض مختارة في قناة **@WafarnalakMasr** باستخدام GitHub Actions. النسخة الأولى تنشر العروض التي تُضاف يدويًا إلى `data/offers.json`، وتوفر إجراءً يدويًا لاختبار اتصال البوت بالقناة.

## المطلوب قبل التشغيل

1. أضف البوت إلى القناة كمسؤول، مع صلاحية نشر الرسائل.
2. من المستودع افتح **Settings → Secrets and variables → Actions → New repository secret**.
3. أنشئ سرًا اسمه `TELEGRAM_BOT_TOKEN` وضع فيه توكن البوت من BotFather. لا تضع التوكن في ملفات المستودع ولا ترسله في المحادثات.
4. افتح تبويب **Actions** وشغّل **Telegram connection test** يدويًا. ستظهر رسالة اختبار في القناة.

## إضافة عرض للنشر

أضف عنصرًا إلى `data/offers.json` مثل المثال التالي، مع استبدال البيانات برابط وسعر تحققت منهما:

```json
[
  {
    "id": "example-001",
    "title": "اسم المنتج",
    "price": "1299 جنيه",
    "old_price": "1799 جنيه",
    "discount_percent": 28,
    "url": "https://www.amazon.eg/dp/EXAMPLE",
    "publish_at": "2026-10-26T17:00:00+03:00",
    "expires_at": "2026-10-27T17:00:00+03:00"
  }
]
```

`publish_at` و`expires_at` يجب أن يحتويَا على المنطقة الزمنية. ينشر النظام العرض في أول تشغيل مجدول بعد موعده. المواعيد المجدولة حاليًا **11:17 صباحًا و5:17 مساءً بتوقيت القاهرة**. يمكن أيضًا تشغيل **Publish due offers** يدويًا من تبويب Actions. بعد نجاح النشر، يسجل النظام معرّف العرض في `data/published.json` حتى لا يعيد نشره.

## حدود النسخة الأولى

- لا يجلب هذا الإصدار المنتجات أو الأسعار تلقائيًا من Amazon؛ أضف العروض بعد التحقق منها يدويًا.
- استخدم رابط Amazon المؤهل لعمولتك بعد الانضمام لبرنامج Amazon Associates. الرابط العادي لا يضمن عمولة.
- تتضمن الرسالة تنبيهًا بأن السعر والتوفر قد يتغيران، وإفصاحًا عن احتمال الحصول على عمولة.
- لا تضع أسرارًا أو بيانات دخول في الملفات العامة.

## تشغيل محليًا

يتطلب Python 3.11 أو أحدث. عيّن `TELEGRAM_BOT_TOKEN` في بيئتك ثم شغّل:

```bash
python scripts/test_telegram.py
python scripts/publish_offers.py
```

يعتمد المشروع على مكتبات Python القياسية ولا يحتاج تثبيت حزم إضافية.
